# 一杯经典 · My Wine

102 款 IBA 经典与 34 款 Innovations 创意鸡尾酒的中英文配方与调制指南。

这个仓库包含网站的静态发布文件，通过 GitHub Pages 提供访问。无需后端或 API 密钥。收藏保存在访问者自己的浏览器中。

配方及照片出处、字体和图标许可见 [SOURCES.md](SOURCES.md) 及相应 assets 目录内的许可文件。照片来源保留原有署名；未授予额外的图片使用许可。

发布来源：main 分支的根目录。

图片统一执行与 ChatGPT Sites 相同的规则：最长边不超过 640px，鸡尾酒图片使用 640×640 画布，杯体居中、主体最大约 480px，艺术图与实拍对齐并保留边距。原文件保存在本地项目外的 `../image-originals/`，不上传到此仓库。原始插画 PNG 保留在创作项目的 `artwork-originals/`。

在用户明确要求部署后，运行 `npm run prepare:deploy`，再推送。该命令会先备份并处理图片，检查像素、哈希、实拍构图及实际页面启动；新实拍需要先在 `image-framing.json` 中记录目视检查后的主体边界与源文件 SHA-256。工具依赖本机 ImageMagick。

经典酒单使用 `cocktails.json` 独立启动。`innovations.json` 为可选扩展：缺失、请求失败或格式错误时，经典酒单仍可使用，创意分类仅在数据加载成功后显示。全部酒款在正常加载时包含 136 款。

更新发布文件后，运行 `npm install --ignore-scripts` 和 `npm test` 检查实际页面启动、搜索、收藏、详情和数据加载失败后的重试。不要只检查 HTTP 200，也不要将其他工作区未完成的启动逻辑直接覆盖到发布版。

支持材料库存多选与 12 种味型组合筛选，收藏和材料保存在当前浏览器。原始高分辨率图片、研究和本地预览截图不包含在发布内容中。
