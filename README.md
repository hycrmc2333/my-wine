# 一杯经典 · My Wine

102 款经典鸡尾酒的中英文配方与调制指南。

这个仓库包含网站的静态发布文件，通过 GitHub Pages 提供访问。无需后端或 API 密钥。收藏保存在访问者自己的浏览器中。

配方及照片出处、字体和图标许可见 [SOURCES.md](SOURCES.md) 及相应 assets 目录内的许可文件。照片来源保留原有署名；未授予额外的图片使用许可。

发布来源：main 分支的根目录。

经典酒单使用 `cocktails.json` 独立启动。`innovations.json` 为可选扩展：缺失、请求失败或格式错误时，经典酒单仍可使用，原创入口仅在数据加载成功后显示。

更新发布文件后，运行 `npm install --ignore-scripts` 和 `npm test` 检查实际页面启动、搜索、收藏、详情和数据加载失败后的重试。不要只检查 HTTP 200，也不要将其他工作区未完成的启动逻辑直接覆盖到发布版。
